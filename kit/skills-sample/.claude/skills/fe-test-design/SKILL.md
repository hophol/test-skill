# 前端测试设计

把需求与技术方案转化为可执行的测试设计。

## 流程

1. 读前端需求说明与技术方案（缺则先指出，不猜）
2. 单元测试清单：纯函数 / hooks 的输入输出表
3. 组件测试要点：渲染、交互、状态变化
4. E2E 场景：主流程一条 + 每个边界条件一条
5. 输出 `fe-test-{功能名}.md`，每条用例关联需求编号（REQ-xxx），章节固定为：单元 / 组件 / E2E / 验收核对表

## 边界

- 不改需求和技术方案，发现问题只提出不实施
- 不写具体测试代码，只出设计
